## Critical Issues Found

### 1. Domain & branding mismatch (repo vs live)

| Location | Brand / Domain |
|----------|----------------|
| Live site | `ImageFormatConverter` / `www.imageformatconverter.in` |
| GitHub repo (before fix) | `ReduceImageSize` / `reduceimagesizeonline.com` |
| Old `imageformatconverter` repo | `ImageConverterPro` / `imageconverterpro.com` |

**Impact:** Wrong canonical signals, broken OG tags, confused crawl budget if old repo deploys.

**Fix applied:** Updated `constants.ts`, `layout.tsx`, `schema.ts`, footer, and homepage to `imageformatconverter.in`.

### 2. 20KB slug inconsistency

- Live canonical URL: `/image-compressor-to-20kb` (ranking at position ~8)
- Repo had: `/compress-image-to-20kb`

**Fix applied:** Renamed slug to `image-compressor-to-20kb` with 301 redirect from old slug. **No changes to 20KB page title, description, FAQs, or compressor logic.**

### 3. Zero AI keyword coverage

Search Console shows **no AI-related queries** ranking yet. Competitors are capturing:

- ai image compressor
- ai photo compressor online
- chatgpt image compressor
- free ai image compressor

**Fix applied:** 6 new AI intent pages + 3 blog posts + footer/homepage AI sections.

### 4. Underperforming high-impression pages

| Page / Query | Impressions | Position | Opportunity |
|--------------|-------------|----------|-------------|
| `/compress-image-to-50kb` | 1,764 | 30.81 | Needs stronger content + internal links |
| `/png-to-jpg` | 1,452 | 30.22 | Add redirect/intent page (done: `png-to-jpg` → converter) |
| `compress image to 50kb` | 85 | 33.95 | Blog + intent linking |
| PDF compressors | 200–600 | 44–51 | Lower priority; separate cluster |

### 5. Sitemap error (live site)

`https://www.imageformatconverter.in/sitemap.xml` returned 500 via fetch tool but 200 via curl — monitor in Search Console.

### 6. Old static repo out of sync

The `imageformatconverter` GitHub repo contains only a legacy `index.html` with wrong branding. Production runs from `reduce-image-size-online` (Next.js).

## On-Page SEO Audit

### Strengths (live site)

- Tool-first layout (compressor above fold) — matches search intent
- Long-form SEO content below tools (~2000+ words auto-generated)
- FAQ schema + HowTo + WebApplication JSON-LD
- Internal linking between KB presets
- India-specific copy (SSC, UPSC, PAN, Aadhaar, passport)
- `lang="en-IN"` on live site
- Canonical URLs per page
- 109+ URLs in sitemap

### Weaknesses

- No dedicated AI landing pages (before this update)
- Homepage under-optimized for India vs 100KB/20KB pages
- `/compress-image-to-50kb` ranking poorly despite demand
- Blog posts link to old `reduceimagesizeonline.com` domain
- No `hreflang` (acceptable for India-only focus with `en-IN`)
- Education calculators (rank calculator) rank but dilute topical focus — consider separate subdomain or clearer silo
